# yxip

用于保存 IP 地址清单和网络测试结果的资料仓库。

## 文件说明

- `yxip.txt`：纯文本 IP 地址列表，每行一个地址。
- `*.csv`：不同批次的 IP 测试结果，文件名由批次标识和时间戳组成。

CSV 文件包含以下字段：

| 字段 | 含义 |
| --- | --- |
| IP地址 | 被测试的 IP 地址 |
| 端口 | 连接端口 |
| 回源端口 | 回源服务端口 |
| TLS | 是否使用 TLS |
| 数据中心 | 数据中心代码 |
| 地区 | 所在地区 |
| 城市 | 所在城市 |
| TCP延迟(ms) | TCP 连接延迟，单位为毫秒 |
| 速度(MB/s) | 测试速度，单位为 MB/s |

## 使用方式

文本列表可直接供逐行读取的网络测试工具使用。CSV 文件可用电子表格软件打开，也可以通过脚本按延迟、速度、地区等字段筛选。

测试结果具有时效性，实际可用性和性能可能随网络环境及测试时间变化，请在使用前重新验证。
